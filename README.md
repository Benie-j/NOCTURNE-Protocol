# NOCTURNE : PROTOCOLE ZÉRO

Prototype de jeu d'action tactique / infiltration pour Android et PC, développé avec Godot 4.4 et GDScript.

## État du projet
Version 0.1.0 : prototype jouable, arène procédurale simple, combat, ennemis poursuivant le joueur, extraction, HUD, commandes clavier/souris et commandes tactiles, sauvegarde locale de progression.

## Commandes
- PC : WASD ou flèches pour bouger, souris pour viser, clic gauche pour tirer, R pour recharger, Échap pour pause.
- Mobile : joystick à gauche, bouton TIR et RECHARGE à droite.

## Compilation Android
GitHub Actions compile un APK debug à chaque push sur `main` ou lancement manuel. L'APK est publié comme artefact du workflow.

## Lancer dans Godot
Ouvrir `project.godot` avec Godot 4.4 ou version compatible.
